# MDownManager - Releases

Public download builds for [MDownManager](https://www.teambotics.app), a local-first Markdown knowledge base with semantic search, AI summaries, security scanning, and a local HTTP API.

MDownManager's source code lives in a private repository. This repo exists so release installers can be downloaded publicly. Builds will be listed under [Releases](https://github.com/nickhilster/MDownManager-releases/releases).
